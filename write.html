草稿和图片先留在这台手机里。发布会写成仓库里的一篇 Markdown，只有站长自己的 GitHub 账号可以写入。站点页面里没有访问令牌。

正在读取配置。

发布前需要完成的一次性设置
  1. 打开 GitHub → Settings → Developer settings → OAuth Apps，新建一个 OAuth App。Homepage URL 填 https://fjh0805.github.io。Callback URL 可以填同一个地址，设备码流程不会用到它。
  2. 在这个 OAuth App 里勾选 Enable Device Flow。复制 Client ID。不要把 Client Secret 写进网页、脚本或仓库。
  3. 用 Cloudflare 部署仓库里的 writer/oauth-proxy。它只转发 GitHub 的两个设备码地址，并加上浏览器需要的 CORS 头，自己不保存密钥。
  4. 把 Worker 的 ALLOWED_ORIGINS 设为 https://fjh0805.github.io。
  5. 把 Client ID 和 Worker 的 https 地址填进 _config.yml 的 writer.client_id、writer.oauth_proxy，提交到 master 等 Pages 重新构建。
  6. 回到这个页面，用 GitHub 登录并在 github.com/login/device 输入验证码。只有账号 fjh0805 能发布。

登录使用的 scope 是 repo，因为 GitHub 写入文件的接口要求它。令牌只放在当前标签页，关掉就消失。可以在 GitHub → Settings → Applications 里随时撤销。
